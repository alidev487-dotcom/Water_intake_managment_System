# Towfiq Abu Hayat MD - Daily Goal Calculation

## File
- src/GoalCalculator.java

## Method
- calculateDailyGoal(double weight)

## Task Explanation
- Calculates recommended daily water intake from weight.
- Uses formula:
  - dailyWaterGoal = weight * 35
- Returns 0 for invalid/non-positive weight.
- Keeps goal-calculation logic separate and reusable.
