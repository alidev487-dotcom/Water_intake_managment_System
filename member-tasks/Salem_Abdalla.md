# Salem Abdalla - Input Handling and Validation

## File
- src/InputHandler.java

## Methods
- readText()
- readInt()
- readDouble()

## Task Explanation
- Handles all keyboard input.
- Ensures empty text is not accepted in readText().
- Ensures only whole numbers are accepted in readInt().
- Ensures only positive decimal numbers are accepted in readDouble().
- Prevents the program from crashing on invalid input by retrying until valid input is entered.
