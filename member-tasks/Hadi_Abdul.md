# Hadi Abdul - Hydration Status Logic

## File
- src/HydrationEvaluator.java

## Method
- hydrationStatus(double total, double goal)

## Task Explanation
- Compares total intake with the user goal.
- Returns status categories:
  - No Goal Set
  - Well Hydrated
  - Almost Achieved
  - Need More Water
  - Dehydrated
- Encapsulates all hydration decision rules in one place.
