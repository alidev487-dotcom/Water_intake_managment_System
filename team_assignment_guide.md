# Daily Water Intake Monitoring System - Team Explanation Guide

This file is a simple guide for every team member to explain their part of the project to the teacher in easy words.

## 1. Project Overview
This project is a Java console application that helps users track their daily water intake. It allows the user to register information, calculate the recommended amount of water, add water consumption records, and display the daily summary.

## 2. What the Program Does
The system performs the following actions:
- Registers a user
- Stores the user’s name, age, gender, and weight
- Calculates the recommended water intake using the formula: weight × 35
- Adds water intake records
- Shows total water consumed
- Shows remaining water needed
- Displays hydration status
- Runs through a simple menu-driven interface

## 3. Main Classes and Their Purpose

### Class 1: User
This class is for the user’s personal information.
It stores:
- Name
- Age
- Gender
- Weight
- Recommended water amount

It is responsible for:
- Saving user details
- Calculating the recommended water intake
- Showing user information

### Class 2: WaterRecord
This class handles the daily water intake records.
It stores the water amounts entered by the user in a list.
It is responsible for:
- Adding water intake records
- Calculating total water consumption
- Finding how much water is still needed
- Checking hydration status
- Showing the history of water intake entries

### Class 3: DailyWaterIntakeSystem
This class is the main system controller.
It is responsible for:
- Showing the menu options
- Taking input from the user
- Sending the user to the correct action
- Running the whole program

## 4. How the Menu Works
The program shows a menu with options such as:
1. User Registration
2. Calculate Recommended Water Intake
3. Add Water Consumption Record
4. View Daily Consumption History
5. Check Hydration Status
6. Display Daily Summary
7. Exit

Each option helps the user perform one task in the system.
